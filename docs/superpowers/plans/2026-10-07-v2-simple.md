# v2 좌표 역계산 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 두 점 좌표(X=북, Y=동)를 넣으면 A→B 수평거리와 방위각을 보여 주는 별도 PWA(`/v2/`).

**Architecture:** `src/v2/inverse.js`(순수 계산·저장) + `src/v2/app.js`(화면). `build.mjs`가 v1·v2를 각각 단일 HTML로 빌드.

**Tech Stack:** 순수 JS, `node:test`, 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-10-07-v2-simple-design.md`

## Global Constraints
- 외부 라이브러리 금지, UI 한국어, 거리 m 소수 3자리, 방위각 1″ 단위 도분초.
- X=북, Y=동, 방위각은 북에서 시계 방향.
- 저장 키 `rb.v2.state`. 인라인 빌드 규칙(한 줄 import, `export function/const`, `calc.js`와 최상위 이름 중복 금지).
- v1 동작·주소는 바뀌지 않는다.

## Review Focus
1. 방위각 359°59′59.6″ → 반올림 시 `0°00′00″` (360°로 표시 금지). Task 1 테스트.
2. 음수·큰 좌표(예: 국가좌표 X 500000, Y 200000) 정밀도. Task 1 테스트.
3. 입력 중 결과만 갱신되어 포커스·커서 유지. Task 2 브라우저 확인.
4. 저장소 접근 불가여도 동작. Task 1 테스트.
5. v1 서비스워커(루트 범위)가 있어도 v2가 열림. Task 3 배포 확인.

### Task 1: 역계산 모델

**Files:** Create `src/v2/inverse.js`; Test `test/v2.inverse.test.js`

**Interfaces:**
- Consumes: `calc.js` `parseNum`.
- Produces:
  - `V2_KEY = 'rb.v2.state'`
  - `inverse(a:{x,y}, b:{x,y}) -> {dist:number, az:number|null}` (az 도, 같은 점이면 null)
  - `formatDms(deg:number) -> string` (`58°48′42″`)
  - `parseState(state) -> {ok:true, a, b} | {ok:false, bad:string[]}` (bad = 형식 오류 칸 키, 빈 칸은 bad 아님)
  - `emptyState() -> {version:1, xa:'', ya:'', xb:'', yb:''}`
  - `loadState(storage) -> State`, `saveState(storage, state) -> boolean`
