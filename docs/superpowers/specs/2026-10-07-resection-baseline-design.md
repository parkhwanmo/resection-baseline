# 후방교회 기선 거리 앱 — 설계

작성일: 2026-10-07

## 1. 목적

토탈스테이션을 **미지점 두 곳(S1, S2)** 에 차례로 세우고, 두 기계점 모두에서 **좌표 없는 공통점**(타겟·프리즘 등)을 관측한다.
앱은 공통점을 이용해 후방교회(자유망원)로 S2의 위치를 S1 기준으로 구하고,
**S1–S2 거리**와 **상대 좌표**(S1, S2, 관측점)를 보여 준다. 결과 확인으로 작업이 끝난다.

- 측량기와 통신하지 않는다. 측량기 화면의 값을 손으로 입력한다.
- 안드로이드 폰에서 오프라인으로 동작하는 웹앱(PWA)으로 만든다.
- 원칙: **현장에서 항상 진행할 수 있어야 한다.** 조건이 나쁘면 막지 않고 결과와 경고를 함께 보여 준다. 계산이 수학적으로 불가능할 때만 멈추고, 무엇이 부족한지 알려 준다.

### 완성 기준
- 좌표를 아는 합성 데이터로 계산한 S1–S2 거리와 상대 좌표가 참값과 **1mm 이내**로 일치한다(무오차 데이터는 0.1mm 이내).
- 폰 크롬에서 비행기 모드로 열고, 입력·계산·저장이 된다.

## 2. 입력

### 2.1 기계점별 공통 입력
- 기계고 HI (m, 기본 0)
- 기계점 좌표 N0/E0/Z0 (m, 기본 0): 좌표 입력 모드에서만 사용한다. 측량기에 설정한 기계점 좌표를 넣으며, 측량기를 0,0,0으로 세웠으면 비워 둔다.

### 2.2 관측점 (점마다 둘 중 하나)
| 모드 | 입력 |
|---|---|
| 관측값 | 점명, 사거리 SD(m), 수평각 HA, 연직각 VA, 프리즘고 HT(m, 기본 0) |
| 좌표 | 점명, N, E, Z (측량기가 표시한 값) |

한 기계점 안에서 두 모드를 섞어 쓸 수 있다.

### 2.3 각도 형식 (설정)
- 수평·연직각 단위: **도분초 `ddd.mmss`** (기본, 예: `123.4530` = 123°45′30″), 십진 도, gon
- 도분초는 `123 45 30`, `123-45-30` 표기도 받는다. 분 또는 초가 60 이상이면 입력 오류로 처리한다.
- 연직각 종류: **천정각**(기본) / 고도각(수평 0°)
- 망원경 반전(정·반) 처리: 천정각이 180°를 넘으면 반위 관측으로 보고 정위로 환산한다. `ZA' = 360° − ZA`, `HA' = HA + 180°`.

### 2.4 점명 매칭
- 앞뒤 공백을 제거하고 대소문자를 무시해서 같은 이름이면 같은 점으로 본다.
- 점명 입력 칸은 다른 기계점에서 이미 쓴 이름을 자동완성으로 제시한다. 오타로 매칭이 깨지는 것을 막기 위해서다.
- 한 기계점 안에서 같은 이름이 다시 나오면 마지막 값만 쓰고, 목록에 "중복"으로 표시한다.

## 3. 계산

### 3.1 로컬 좌표 (기계점마다)
기계점 지면 표지를 원점으로 하고, x=E 방향, y=N 방향(수평각 0° 방향), z=위쪽으로 둔다.

- 관측값 모드:
  - `ZA` = 천정각 (고도각이면 `90° − VA`), 반위면 2.3에 따라 환산
  - `HD = SD·sin ZA`
  - `x = HD·sin HA`, `y = HD·cos HA`
  - `z = SD·cos ZA + HI − HT`
- 좌표 모드: `x = E − E0`, `y = N − N0`, `z = Z − Z0`
  - 측량기에서 기계고·프리즘고를 이미 반영했다고 보고, HI는 더하지 않는다.
  - 이 경우 z는 측량기에 설정한 Z0 기준이다.

### 3.2 S2 → S1 정합 (후방교회)
공통점 집합 C(제외 표시한 점 제외, n = |C|)에 대해 S1 로컬 좌표 P₁ᵢ, S2 로컬 좌표 P₂ᵢ를 짝짓는다.

- 수평: 강체 변환(축척 1 고정) `P₁ = R(θ)·P₂ + t`를 최소제곱으로 푼다(닫힌 해).
  - 무게중심 `c₁, c₂`, 중심화 `a = P₂ − c₂`, `b = P₁ − c₁`
  - `θ = atan2(Σ(aₓb_y − a_y bₓ), Σ(aₓbₓ + a_y b_y))`
  - `t = c₁ − R(θ)·c₂`
- 수직: `tz = mean(z₁ᵢ − z₂ᵢ)`
- **S1 좌표계에서 S2의 위치 = (tₓ, t_y, tz)**

### 3.3 결과값
- S1–S2 수평거리 `HD = √(tₓ² + t_y²)`, 고저차 `ΔZ = tz`, 사거리 `SD = √(HD² + ΔZ²)`
- 공통점별 잔차: 수평 `|P₁ − (R·P₂ + t)|`, 수직 `z₁ − (z₂ + tz)`
- RMS: 수평과 수직을 각각 따로 계산한다.

### 3.4 상대 좌표계
- **기본: S1 = (0, 0, 0), S1→S2 방향 = +X** → `S2 = (HD, 0, ΔZ)`
- 설정으로 바꿀 수 있는 대안: S1 로컬 축을 그대로 쓴다(S1 수평각 0° 방향 = +Y).
- 모든 관측점을 이 좌표계로 변환한다.
  - 양쪽에서 관측한 점(공통점, 제외 점 포함)은 두 추정값의 평균을 쓴다.
  - 한쪽에서만 관측한 점은 그 값 하나를 쓴다.
  - 표에는 어느 기계점에서 관측했는지(S1 / S2 / 양쪽)를 함께 표시한다.

### 3.5 판정과 경고 (멈추지 않음)
| 상황 | 동작 |
|---|---|
| 공통점 < 2 | 계산 불가. 각 기계점의 점명 목록과 "같은 이름으로 2점 이상 관측 필요"를 표시 |
| 공통점 = 2 | 계산함. 노란 경고 "검증 불가 — 3점 이상 권장" |
| 공통점이 서로 너무 가까움 (공통점 최대 간격 < 0.5m) | 계산함. 노란 경고 "공통점 배치가 좁아 방향 오차가 큼" |
| 잔차가 허용값 초과 (기본 수평 5mm, 수직 5mm, 설정에서 변경) | 해당 행 빨간색. 잔차가 가장 큰 점에 "제외 후 재계산" 버튼 표시 |
| 입력 형식 오류 | 그 점만 계산에서 빠지고, 목록에 오류를 표시 |

- 사용자는 공통점을 체크 해제(제외)해서 즉시 재계산할 수 있다. 남은 공통점이 2점이 될 때까지 제외할 수 있다.

## 4. 화면 (모바일 세로, 한 손 입력)

1. **작업 목록**: 새 작업, 열기, 이름 변경, 삭제, 전체 백업(JSON 저장), 백업 불러오기
2. **작업 화면**: 상단 탭 `S1 | S2 | 결과 | 설정`
   - **S1 / S2 탭**
     - 기계고, 기계점 좌표 N0/E0/Z0(접힘)
     - 관측점 목록(점명, 모드, 핵심값, 상태)
     - "점 추가" 버튼 → 입력 폼(모드 토글, 숫자 키패드). 저장하면 다음 점을 연이어 입력한다.
     - 점을 눌러 수정 또는 삭제
   - **결과 탭**
     - 크게 표시: S1–S2 수평거리, 사거리, 고저차 (mm 단위까지, 소수 3자리 m)
     - 상태 배지: 정상 / 경고 / 계산 불가
     - 공통점 잔차 표(제외 체크박스, 수평·수직 잔차, RMS)
     - 상대 좌표 표(점명, X, Y, Z, 출처)
     - CSV 내보내기, 결과 텍스트 복사
   - **설정 탭**: 각도 단위, 연직각 종류, 허용 잔차, 상대 좌표 축 방식

## 5. 저장·내보내기
- 입력할 때마다 브라우저 `localStorage`에 자동 저장한다(키 `rb.jobs.v1`, 버전 필드 포함).
- 백업: 전체 작업을 JSON 파일로 저장하고 다시 불러올 수 있다(브라우저 데이터 삭제 대비).
- CSV: 결과(기선 거리, 잔차, 상대 좌표)를 UTF-8 BOM 포함 CSV로 저장한다. 엑셀에서 한글이 깨지지 않게 하기 위해서다.

### 데이터 모델
```
Job { id, name, createdAt, updatedAt,
      settings { angleUnit: 'dms'|'deg'|'gon', vAngle: 'zenith'|'elevation',
                 tolH: 0.005, tolV: 0.005, axis: 'baseline'|'s1' },
      stations { S1: Station, S2: Station },
      excluded: [pointName] }
Station { hi, n0, e0, z0, obs: [Obs] }
Obs { id, name, mode: 'polar'|'coord', sd, ha, va, ht, n, e, z }
```
입력값은 사용자가 친 문자열 그대로 저장하고, 해석은 계산할 때 한다. 각도 단위 설정을 바꿔도 원래 입력이 보존되게 하기 위해서다.

## 6. 구조
```
src/calc.js     순수 계산 (각도 해석, 로컬 좌표, 정합, 상대 좌표, 판정) — DOM 없음
src/store.js    localStorage 저장/불러오기, 백업 JSON, CSV 생성
src/app.js      화면과 이벤트
src/index.html, src/style.css
test/*.test.js  node --test (calc, store)
build.mjs       src를 dist/index.html 한 파일로 합치고, manifest·서비스워커·아이콘 복사
dist/           배포 산출물 (index.html, manifest.webmanifest, sw.js, icon.svg)
```
- 의존성 없는 순수 JS(ES 모듈)로 작성한다. 테스트는 Node 내장 `node:test`를 쓴다.
- `calc.js`는 DOM을 몰라야 한다. 화면은 `calc.solve(job)` 결과만 그린다.

## 7. 배포
- PWA: `manifest.webmanifest`와 서비스워커(캐시 우선)를 넣는다. 한 번 열면 이후 오프라인으로 동작하고, "홈 화면에 추가"로 설치한다.
- 호스팅: GitHub Pages(HTTPS가 필요해서)를 쓴다. **저장소 생성과 공개 푸시는 사용자 확인 후에 한다.**
- 대안: `dist/index.html` 한 파일만으로도 동작한다. PC 브라우저 테스트용이다.

## 8. 테스트
- 각도 해석: 도분초·십진 도·gon, 구분자 표기, 분·초 ≥ 60 오류, 고도각 변환, 반위 환산
- 합성 시나리오: 세계 좌표의 S1, S2, 타겟 5개 → 각 기계점을 임의 방향으로 세운 관측값 생성 → 복원 거리 오차 < 0.1mm
- 좌표 모드 + 기계점 좌표 0이 아닌 경우, 그리고 관측값·좌표 혼합 입력
- 공통점 2점(경고), 1점(계산 불가), 좁은 배치(경고)
- 잡음(±2mm) 데이터는 1mm 기준 이내, 한 점에 50mm 착오 → 최대 잔차 점으로 지목되고 제외 후 정상
- 상대 좌표: S2 = (HD, 0, ΔZ), 양쪽 관측점 평균
- 저장: 저장→불러오기 왕복, 백업 JSON 왕복, CSV 헤더·BOM

## 9. 범위 밖
- 측량기 블루투스·파일 연동
- 기계점 3개 이상, 망조정
- 측설 안내, CAD 내보내기
- 축척 계수 추정 (축척 1 고정)
