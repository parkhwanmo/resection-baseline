# v2 — 두 점 좌표 역계산 (거리·방위각) 설계

작성일: 2026-10-07

## 1. 목적
알고 있는 두 점 A, B의 좌표를 입력하면 **A→B 수평거리와 방위각만** 보여 주는 단순 화면.
v1(후방교회 기선 거리)은 그대로 두고 별도 주소 `…/resection-baseline/v2/`에 별도 PWA로 배포한다.

### 완성 기준
- 사분면·축 방향 테스트 케이스에서 거리 1e-9 m, 방위각 1″ 이내로 정확하다.
- 폰 크기 브라우저에서 입력 즉시 결과 표시, 새로고침 후 입력 유지, 오프라인 동작.

## 2. 좌표 표기
- **X = 북, Y = 동** (측량 표기). 방위각 = 북(X+)에서 시계 방향, 0° ≤ α < 360°.
- 수평거리만 계산한다 (Z 없음).

## 3. 화면 (한 페이지)
- 상단 바: 제목 "좌표 거리·방위각", `지우기` 버튼(확인 후 비움).
- 점 A: X(북), Y(동) / 점 B: X(북), Y(동) — 숫자 키패드(`inputmode="decimal"`).
- 결과: **거리** `48.860 m` (소수 3자리), **방위각** `58°48′54″ (A→B)` (1″ 단위).
- 네 칸이 모두 유효할 때만 결과 표시. 아니면 "A, B 좌표를 입력하세요".
- 값이 있는데 형식이 틀린 칸은 빨간 테두리. 쉼표 소수점 허용(`12,5`).
- A = B이면 거리 `0.000 m`, 방위각 `—`.

## 4. 계산
- `ΔX = XB − XA`, `ΔY = YB − YA`
- 거리 `D = √(ΔX² + ΔY²)`
- 방위각 `α = atan2(ΔY, ΔX)`, 음수면 +360°
- 도분초 표시: 초를 정수로 반올림하고 60″→1′, 60′→1°, 360°→0° 올림 처리.

## 5. 저장
`localStorage` 키 `rb.v2.state`에 입력할 때마다 저장: `{ version: 1, xa, ya, xb, yb }` (문자열).
깨진 값·접근 불가 시 빈 상태로 시작하고 앱은 동작한다.

## 6. 구조·배포
```
src/v2/inverse.js   inverse, formatDms, loadState, saveState (DOM 없음)
src/v2/app.js       화면
src/v2/index.html, src/v2/style.css, src/v2/manifest.webmanifest
build.mjs           v1 → dist/, v2 → dist/v2/ (sw.js·icon.svg 템플릿 공유)
```
- v2 스크립트 묶음: `calc.js`(parseNum 재사용) + `v2/inverse.js` + `v2/app.js`.
- v2 서비스워커는 `v2/` 범위만 담당한다.

## 7. 테스트
- `inverse`: 4개 사분면, 축 방향(0°, 90°, 180°, 270°), 같은 점(방위각 null)
- `formatDms`: 58°48′42″(=58.8117°) → `58°48′42″`, 59.9999° 반올림 올림 → `60°00′00″`, 359.99999° → `0°00′00″`
- `loadState/saveState`: 왕복, 깨진 JSON·접근 불가 → 빈 상태
- 브라우저: 입력 → 결과, 오류 칸 표시, 새로고침 유지, 지우기
