# 후방교회 기선 거리

토탈스테이션을 미지점 두 곳(S1, S2)에 차례로 세우고, 양쪽에서 **같은 공통점**(좌표 없는 타겟·프리즘)을 관측하면
S1–S2 거리(수평거리·사거리·고저차)와 상대 좌표를 계산하는 오프라인 모바일 웹앱입니다.
측량기 화면의 값을 손으로 입력합니다.

| 앱 | 주소 | 하는 일 |
|---|---|---|
| v1 후방교회 기선 거리 | https://parkhwanmo.github.io/resection-baseline/ | 미지점 S1·S2 관측값 → 기선 거리·잔차·상대 좌표 |
| v2 좌표 거리·방위각 | https://parkhwanmo.github.io/resection-baseline/v2/ | 두 점 좌표 → 거리·방위각 / 한 점 + 거리·방위각 → 두 번째 점 좌표 |

## v2 좌표 거리·방위각
- **거리·방위각 구하기**: 점 A, B의 X(북)·Y(동)를 넣으면 A→B 수평거리(m, 소수 3자리)와 방위각(북에서 시계 방향, 1″ 단위)이 바로 나옵니다.
- **B 좌표 구하기**: 점 A의 X·Y와 거리, 방위각(`ddd.mmss`)을 넣으면 B의 X·Y가 나옵니다.
- 입력은 자동 저장되고 `지우기`로 비웁니다. 홈 화면에 따로 설치할 수 있습니다.

## v1 사용 순서

1. **새 작업**을 만듭니다.
2. **S1 탭**: 기계고를 입력하고, 공통점 관측값을 `+ 관측값`으로 입력합니다(사거리, 수평각, 천정각, 프리즘고). `저장 후 다음 점`으로 연속 입력합니다.
3. **S2 탭**: 기계를 옮겨 **같은 점명**으로 같은 공통점을 관측해 입력합니다. 3점 이상을 권장합니다.
4. **결과 탭**: S1–S2 거리, 공통점 잔차, 상대 좌표를 확인합니다.
   - 허용 잔차(기본 5mm)를 넘는 점은 빨간색으로 표시됩니다. 체크를 해제하거나 `제외 후 재계산`을 누르면 그 점을 빼고 다시 계산합니다.
   - 결과는 `CSV 저장`이나 `결과 복사`로 가져갈 수 있습니다.

### 입력 형식
- 각도 기본값은 도분초 `ddd.mmss`입니다. 예: `123.4530` = 123°45′30″, `90.05` = 90°05′00″. `123 45 30` 표기도 됩니다.
- 설정 탭에서 십진 도 / gon, 천정각 / 고도각을 바꿀 수 있습니다.
- 반위 관측(천정각 > 180°)은 자동으로 정위로 환산합니다.
- 측량기가 좌표(N/E/Z)를 보여 주면 `+ 좌표`로 입력할 수 있습니다. 측량기에 기계점 좌표를 설정했다면 기계점 좌표 N0/E0/Z0에 같은 값을 넣습니다.
- 점명은 대소문자와 앞뒤 공백을 무시하고 매칭합니다.

### 상대 좌표
- 기본은 S1 = (0, 0, 0), S1→S2 방향 = +X입니다. 설정에서 "S1 수평각 0° = +Y"로 바꿀 수 있습니다.
- 기계고와 프리즘고를 넣으면 Z는 지면 표지 기준이고, 비워 두면 기계 중심 기준입니다.

### 데이터
- 입력은 이 브라우저에 자동 저장됩니다. 브라우저 데이터를 지우면 함께 사라지므로, 작업 목록의 **백업 저장**(JSON)으로 보관하세요.

## 설치
- `dist/` 폴더를 HTTPS로 호스팅합니다(예: GitHub Pages). 폰 크롬에서 열고 메뉴 → **홈 화면에 추가**를 누르면, 이후에는 오프라인으로 동작합니다.
- PC에서는 `dist/index.html`을 바로 열어도 동작합니다(오프라인 설치 기능 제외).

## 개발
```
npm test        # 계산·저장 테스트 (node:test)
npm run build   # src → dist/ (v1), dist/v2/ (v2) — 각각 단일 index.html + manifest + 서비스워커 + 아이콘
```
- `src/calc.js`: 계산(각도 해석, 로컬 좌표, 2D 강체 최소제곱 정합, 상대 좌표, 판정)
- `src/store.js`: 저장·백업·CSV
- `src/app.js`: 화면
- `src/v2/inverse.js`, `src/v2/app.js`: v2 좌표 역계산
