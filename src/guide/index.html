설치 방법 (안드로이드)

  1. 위 QR을 폰 카메라로 스캔하거나 열기를 눌러 크롬으로 엽니다.
  2. 오른쪽 위 메뉴 ⋮ → 앱 설치(또는 홈 화면에 추가)를 누릅니다.
  3. 홈 화면과 앱 목록에 아이콘이 생깁니다. 두 앱은 따로 설치합니다.
  4. 설치 후 한 번은 인터넷이 될 때 열어 주세요. 그다음부터는 비행기 모드에서도 열립니다.

후방교회 기선 거리 (v1) 사용 순서

  1. + 새 작업을 만듭니다.
  2. S1 탭: 기계고를 넣고, 공통점을 + 관측값으로 입력합니다 (사거리, 수평각, 천정각, 프리즘고).
  3. S2 탭: 기계를 옮겨 같은 점명으로 같은 공통점을 관측해 입력합니다. 3점 이상 권장.
  4. 결과 탭: S1–S2 거리, 공통점 잔차, 상대 좌표를 확인합니다. 허용 잔차(기본 5mm)를 넘는 점은 빨간색 — 체크 해제로 빼고 다시 계산합니다.

각도는 도분초 ddd.mmss 로 입력합니다. 예: 123.4530 = 123°45′30″, 90.05 = 90°05′. 설정 탭에서 십진 도·gon, 고도각으로 바꿀 수 있습니다.

좌표 거리·방위각 (v2) 사용법

  • 거리·방위각 구하기: 점 A, B의 X(북)·Y(동)를 넣으면 A→B 거리(m)와 방위각(북에서 시계 방향, 1″ 단위)이 바로 나옵니다.
  • B 좌표 구하기: 점 A의 X·Y와 거리, 방위각(ddd.mmss)을 넣으면 점 B의 X·Y가 나옵니다.
  • 입력은 자동 저장되고 지우기로 비웁니다.

알아 두기

  • 입력한 데이터는 각자 폰에만 저장되고 서버로 전송되지 않습니다.
  • 크롬 사이트 데이터를 지우면 입력도 지워집니다. v1은 작업 목록의 백업 저장으로 파일을 보관할 수 있습니다.
  • 앱이 업데이트되면 인터넷 연결 시 다음에 열 때 자동으로 새 버전이 적용됩니다.
  • 계산 결과는 현장 확인용입니다. 중요한 성과는 측량기·정식 프로그램 결과와 대조해 주세요.
